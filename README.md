# Leo's Portfolio
Personal portfolio website for Australian data analyst / health data science job applications.

Tech Stack: Next.js 15, Tailwind CSS, Framer Motion, Recharts, Notion API
Deployment: Vercel

Features
- 📄 Timeline resume
- 📊 Filterable data science projects gallery
- 🧩 MBTI & skill radar dashboard
- 📸 Hobby masonry gallery
- 📝 Markdown blog powered by Notion
